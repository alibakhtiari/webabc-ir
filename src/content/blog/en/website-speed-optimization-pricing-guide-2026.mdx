## 2. Google Core Web Vitals 2026 Standards

Google has fully migrated its user experience signals in 2026. The most critical change is the retirement of First Input Delay (FID) in favor of **Interaction to Next Paint (INP)**:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                    2026 Core Web Vitals Thresholds                      │
├─────────────────────────┬───────────────────┬───────────────────────────┤
│ Metric                  │ Good Threshold    │ What It Measures          │
├─────────────────────────┼───────────────────┼───────────────────────────┤
│ INP (Interaction to     │ < 200 ms          │ Latency of all user taps, │
│ Next Paint)             │ (Ideal < 100 ms)  │ clicks, and key presses   │
│                         │                   │ throughout the visit      │
├─────────────────────────┼───────────────────┼───────────────────────────┤
│ LCP (Largest Contentful │ < 2.5 seconds     │ Render duration of main   │
│ Paint)                  │ (Ideal < 1.8 s)   │ viewport image or heading │
├─────────────────────────┼───────────────────┼───────────────────────────┤
│ CLS (Cumulative Layout  │ < 0.1             │ Visual unexpected shifts  │
│ Shift)                  │ (Ideal < 0.05)    │ and button jumping        │
├─────────────────────────┼───────────────────┼───────────────────────────┤
│ TTFB (Time to First     │ < 800 ms          │ Server response time to   │
│ Byte)                   │ (Ideal < 200 ms)  │ browser initial request   │
└─────────────────────────┴───────────────────┴───────────────────────────┘
```

Failing any of these thresholds in Chrome User Experience Report (CrUX) data directly harms your mobile rankings and reduces Google AI Overview extraction likelihood.
