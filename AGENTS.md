# AGENTS.md — webabc.ir

Multilingual (fa/en/ar) Astro 7 static site served through a Cloudflare Worker.
This file is **operational**: the invariants that break production, the gates that
enforce them, and the traps that are not discoverable from the code alone.

For *why* the SEO work is happening, read [`docs/audit/ACTION-PLAN.md`](docs/audit/ACTION-PLAN.md).
Its Completed ledger is the record of what shipped and in which commit. Do not
duplicate it here.

## 1. Commands & Deployment

Hosted on Cloudflare (Worker + static assets), **automatically deployed on git push to `main`**.

```bash
npm run dev          # local dev server
npm run build        # the real pipeline — see below, do not shortcut to `astro build`
npm run lint         # astro check (templates + TypeScript across all files)
npm test             # verify-agentic.mjs (content negotiation, 404, schema, llms.txt, ai-catalog)
npm run deploy       # manual fallback: build + wrangler deploy
```

`npm run build` is an **ordered pipeline**, and the order is load-bearing:

```
resolve-sitemap-lastmod.mjs  →  generate-og-manifest.mjs
  →  generate-llms-index.mjs  →  generate-llms-full.mjs
  →  generate-ai-catalog.mjs
  →  astro build
  →  generate-markdown-representations.mjs   (writes .md siblings next to HTML)
  →  verify-hreflang-parity.mjs              (gates the build; exits 1 on drift)
```

Running `astro build` alone skips `lastmod` resolution, both `llms.txt` corpora, the
`ai-catalog.json` manifest, the markdown representations, and the hreflang gate.

### Dependency updates & versioning

- Check updates periodically using `ncu`.
- **Only update backwards-compatible packages (Patch and Minor).** Do not blindly bump breaking Major versions (e.g. `@astrojs/mdx` major, `eslint` major, `typescript` major) without a dedicated migration pass.
- **Bump minor version** in `package.json` (`1.0.0` → `1.1.0` → `1.2.0`) whenever safe dependency updates, optimization batches, or feature milestones ship.
- After updating packages or dependencies, always run the full verification battery: `npm run lint && npm test && npm run build`.

### Blog gates — run manually, they are not in `npm test`

```bash
python3 scripts/verify-blog-spec.py      # word band + frontmatter contract
python3 scripts/verify-blog-parity.py    # cross-locale structural parity
```

**Two traps here, both verified 2026-10-05:**

1. **`verify-blog-spec.py` only checks 8 of the 38 EN posts.** It iterates
   `scripts/blog-links-baseline.json`, not the content directory. The other 30
   posts have **no spec gate**. Do not read a green run as "all posts pass".
2. **It hardcodes `updatedDate: 2026-09-23`.** Any legitimate future bump fails with
   `updatedDate not 2026-09-23` — even though the standing rule (§4) *requires* you
   to bump it. If you legitimately edit one of the 8 covered posts, update the
   regex in `scripts/verify-blog-spec.py` in the same commit. Do not "fix" it by
   leaving a stale `updatedDate`.

## 2. Invariants — breaking any of these is a production incident

| # | Rule | Enforced by |
|---|---|---|
| 2.1 | Blog slugs are **byte-identical across fa/en/ar**. Renaming one without mirroring all three breaks hreflang and every internal link. | `verify-hreflang-parity.mjs` |
| 2.2 | `public/_redirects` and `STATIC_REDIRECTS` in `worker.ts` must list the **same** mappings. | `verify-agentic.mjs` §11 |
| 2.3 | Root `/` geo-redirect stays **302**, never 301. A 301 would poison browser/edge caches for anyone who changes region, and locale-by-IP is exactly what Google says not to make permanent. | `worker.ts:385-394` |
| 2.4 | Trailing slash is canonical. Bare paths 301 at the edge. | `worker.ts` |
| 2.5 | `.md` siblings stay `noindex, follow` **with** a `Link: rel="canonical"` to the HTML path. Only `404.md` omits the canonical (it points at a 4xx). | `verify-agentic.mjs` §10 |
| 2.6 | `Vary: Accept` must survive on negotiated content, and any HTML cache rule must not drop it — otherwise markdown/HTML representations cross-contaminate. | `worker.ts` + §10 |
| 2.7 | Only `webabc.ir` is indexable. Any other hostname (workers.dev, staging) must get the noindex header. | `CANONICAL_HOST` |
| 2.8 | Arabic fonts are self-hosted in `public/fonts/ar/` behind `@font-face`. **Do not reintroduce `fonts.googleapis.com` / `fonts.gstatic.com`** — they were removed to kill render-blocking CSS. | grep |
| 2.9 | Every `updatedDate` bump ships **in the same commit** as its content edit. Never backdate `date:`. | review |
| 2.10 | Future publishes are staggered — no bulk days. | review |
| 2.11 | `category` stays **English in all three locales**, even where the title and body are translated. | convention |
| 2.12 | Never bypass `scripts/resolve-sitemap-lastmod.mjs` — it reads `updatedDate` → `date`. | review |
| 2.13 | `public/ai-catalog.json` must be generated by `scripts/generate-ai-catalog.mjs` on build and asserted by `verify-agentic.mjs` §13 (all 21 tools + 12 services in 3 locales). | `verify-agentic.mjs` §13 |
| 2.14 | `llms.txt` link counts and section counts must remain identical across all 3 locales (`en`/`fa`/`ar`) with root acting as the language router. | `scripts/generate-llms-index.mjs` |

## 3. Content rules

[`docs/BLOG-REWRITE-SPEC.md`](docs/BLOG-REWRITE-SPEC.md) is the **binding contract**.
Read it before editing any post. Machine-checked thresholds:

| Rule | Value |
|---|---|
| Body length | 1500–2400 words (`>2400` is a hard fail; merge math will not fit) |
| `title` | ≤ 60 characters |
| `description` | 150–160 characters |
| `keyTakeaways` | 4–5 items |
| `faq` | 3–5 items |
| `readTime` | `max(1, round(words / 200))` — must match exactly |
| Stray `# ` in body | forbidden (H1 lives in the layout) |
| Horizontal rules in body | max 1 |
| Paragraph | ≤ 150 words |
| H2 opener | 40–60 words |
| Internal links | must not drop any link in the baseline manifest |

**Honesty rules — these override SEO pressure:**

- **No fabricated statistics, ever.** Cite a source path or state that no data exists.
- Portfolio percentage claims must match what the page actually shows. There have
  been three separate reconciliation passes; check `results[]` against frontmatter
  before editing either.
- No invented case studies.
- Vision-2030 / market framing is not permitted without repo facts.

## 4. SEO data tooling

Credentials: `docs/GOOGLE-API-SETUP.md`. Secrets live in `.secrets/` (mode 600,
gitignored). **Never commit them, never echo them into a committed file, never
paste a real secret into a document.** `~/.config/claude-seo` is a symlink to
`.secrets/`.

**Always invoke skill scripts through the runner** — it manages the venv:

```bash
cd /Users/alib/.agents/skills/blog-google/scripts
python3 run.py google_auth.py --check              # tier report
python3 run.py gsc_query.py --property sc-domain:webabc.ir --json
python3 run.py gsc_inspect.py <url> --json
python3 run.py pagespeed_check.py <url> --json
```

Bare `python3 gsc_query.py` fails — `google-auth` and
`google-api-python-client` are not in the system interpreter.

### Measurement traps

- **CrUX will never return data for this site.** It answers `404 NOT_FOUND`,
  meaning enabled API + valid key + origin below the Chrome traffic threshold.
  Do not report field LCP/INP/CLS as measured. PSI Lighthouse lab scores are the
  only performance evidence available, and they must be labelled as lab.
- **`seo title checker for blog by webnewstips com`** is a competitor-branded
  query: ~30% of property impressions, structurally 0 clicks, excluded from every
  CTR figure. The exclusion applies at the **Queries sheet only** — it has no page
  dimension, so never subtract it from a page row.
- **GSC Pages lists `/x/` and `/x` as separate rows.** Always sum both before
  comparing a URL across exports. Convention is recorded in the baseline JSON.
- The `Queries` sheet has **no page dimension**. Query→page attribution requires
  the API, not the xlsx.
- The Pages sheet sum can exceed the Chart total — GSC computes each sheet
  independently. `matches_expected: false` is expected, not a bug.
- GSC data lags 2–3 days. A post published 6 days ago showing 0 impressions is
  *unmeasurable*, not failed. Do not judge it early.
- **`|` inside a markdown table cell rags the table**, even inside backticks.

### Do not add

`WebSite.SearchAction` (no site search) · `BreadcrumbList` on the homepage
(self-referential) · `QAPage` (FAQs are editorial) · `HowTo` (deprecated 2023) ·
fabricated `AggregateRating`/`Review` · changing the root 302 to 301.

The **Indexing API is for `JobPosting` and broadcast/video pages only.** Do not
submit normal pages to it — it violates Google's policy. Always tell the user this.

## 5. Workflow

1. Read `docs/audit/ACTION-PLAN.md` first. If the task touches an item with an open
   falsifiability clock, **do not pre-empt it** — read the clock and check whether it
   has expired.
2. Every change to a money page, a tool page, or a redirect records evidence in the
   ACTION-PLAN ledger: what shipped, which commit, and the falsifiability check
   with its due date.
3. Ship locales in parallel — en/fa/ar in one commit unless the plan says fa-first
   for a conversion-market test.
4. Commits are Conventional Commits with a scope and the plan item referenced:
   `fix(seo): front-load outcome metrics into Remido snippets (§3.2b)`.
   `docs(audit): …` for ledger-only changes.

## 6. Layout

```
src/content/blog/{en,fa,ar}/   38 posts × 3 locales, MDX, slugs byte-identical
src/pages/[lang]/              every route is locale-parameterised — add [lang], never a bare path
src/i18n/{lang}/               translations, incl. tools/*.json per tool
src/components/astro/          TLDR, FAQ, Breadcrumbs, TableOfContents, OptimizedImage
worker.ts                      edge: geo-302, trailing-slash 301, .md noindex, content negotiation
public/_redirects              redirect source #1
public/llms.txt                language router; public/{lang}/llms.txt + llms-full.txt generated
scripts/                       generators + gates (see §1)
docs/audit/                    findings/, ACTION-PLAN.md, CTR baselines
docs/BLOG-REWRITE-SPEC.md      binding content contract
docs/GOOGLE-API-SETUP.md       credential restore procedure (no secrets in it)
```

Adding a page means adding it under `[lang]/` in all three locales, or hreflang
parity fails the build.
